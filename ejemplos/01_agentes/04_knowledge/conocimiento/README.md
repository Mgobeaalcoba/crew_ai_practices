# conocimiento/

Documentos que el ejemplo [04_knowledge](..) indexa como knowledge.

- `politicas.md`: políticas de una ferretería ficticia ("La Tuerca"): devoluciones, garantía, envíos y horarios.

Podés agregar archivos acá y sumarlos a `fuentes()` en `main.py`. Si modificás un documento ya indexado, borrá `db/` para que se vuelva a indexar.
